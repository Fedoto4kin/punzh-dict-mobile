# Функции первой версии (v1)

Офлайн-клиент словаря Пунжиной для Android. Версия клиента — строка
`version:` в [`pubspec.yaml`](../pubspec.yaml) (сейчас `1.0.x`).

Семантика поиска и UI: [`DICTIONARY.md`](DICTIONARY.md).  
Сборка и релизы: [`DEVELOPMENT.md`](DEVELOPMENT.md), [`AGENTS.md`](../AGENTS.md).  
Пакет данных (контракт): sibling
[`punzh-dict/docs/plans/mobile-pack-contract.md`](../../punzh-dict/docs/plans/mobile-pack-contract.md).

## Назначение

Пользоваться словарём **без сети**: указатель, поиск KRL/RU, карточка статьи,
пометы, закладки. Seed БД в APK; при наличии сети — опциональное обновление
пакета с сайта. Это ограниченный клиент веб-версии: ontology, AI-поиск и
расширенный русский поиск сайта **не** входят в v1.

## Функции

### Алфавитный указатель

- Буквы карельского алфавита → список лемм (`first_letter`, сортировка
  `sort_key`).
- Пагинация / n-gram scrubber на больших буквах.
- Фильтры по пометам на указателе **не** применяются.

### Поиск

| Направление | Поведение |
|-------------|-----------|
| **KRL** (латиница / карельская орфография) | Полное LIKE по индексу `words` (как на сайте: `.` / `?`, без авто-`%`). Пустая выдача → подсказки «Возможно вы искали» (Levenshtein ≤ 2). |
| **RU** (кириллица) | Префикс по `translations.rus_word` (`foo%`, ё→е). Без лемм, стопов, multi-word OR. |

Большая выдача использует тот же scrubber / окна страниц, что указатель.

### Пометы (фильтры)

- Только после KRL-поиска с непустой выдачей.
- Типы 1–4 (radio ≤1 в группе, AND между типами); фразеологизмы — отдельный флаг.
- Фасеты из выдачи; неприменимые комбинации disabled.
- Полоска скрыта, если реального выбора нет.

### Карточка статьи

- HTML статьи + дополнения.
- Переходы по связям «см.» / «от» (стек карточек; system back = pop).
- Закладка (звезда); список в меню; хранение вне пакета БД (переживают update);
  лимит 100.

### Меню

| Пункт | Содержание |
|-------|------------|
| Как искать | Краткая офлайн-справка |
| О словаре | О издании Пунжиной; ссылка на сайт |
| О приложении | Версия + краткий текст клиента |
| Закладки | Список; свайп удаляет |
| Обновление БД | Манифест → download → sha256 → атомарная замена |
| Бренд | Логотип; «КарНЦ РАН» без гиперссылки |

### Данные и обновление

- First-run: копия seed из assets → runtime sqlite (сеть не нужна).
- Update path: `…/mobile-pack/manifest.json`; проверки `schema_version`,
  `min_app`, `sha256`.
- Источник пакета — Django-экспорт в **punzh-dict** (`export_mobile_db`).

## Вне v1 (сознательно)

- Ontology / semantic fields / keywords / AI-поиск.
- Леммы RU, pymorphy, стопы, `?f=`, expand по «см.» в поиске.
- Live REST к Postgres; авторизация; админка в приложении.
- Сложный fuzzy KRL с триграммами сайта.
- iOS-сборка как целевой релиз (стек Flutter допускает позже).
- Отдельная страница приложения на сайте (вместо sticky-баннера) — по
  готовности витрин; не функция клиента.

Раздача в RuStore / прямая APK — операционный контур релиза
(см. [`AGENTS.md`](../AGENTS.md), [`store/rustore/`](../store/rustore/)), не
набор функций словаря.
