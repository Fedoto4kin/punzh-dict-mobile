# Ручной регресс

Прогон на устройстве / USB debug. Seed: актуальный `assets/dict.sqlite`
(`scripts/sync_seed.sh`) или уже установленный runtime-пакет.

Отмечать: `[ ]` → `[x]`. Баг — кратко под пунктом (шаги / ожидание / факт).

Перед прогоном: `flutter test` и `flutter analyze` зелёные; в «О приложении»
версия = `pubspec` (`1.0.0+19` или новее).

---

## 0. Старт

- [ ] Холодный запуск: без краша, открывается указатель (не пустой экран)
- [ ] Есть полоса букв KRL; выбранная буква подсвечена
- [ ] При overflow полосы: стрелки по краям видны, **не** поверх чипов; тап сдвигает полосу
- [ ] Drawer открывается (меню / логотип / «КарНЦ РАН» без ссылки)

## 1. Алфавитный указатель

- [ ] Переключение буквы тапом и свайпом пейджера — список меняется
- [ ] На большой букве (A / K / …) слева n-gram scrubber; тап по метке прыгает к зоне
- [ ] Последняя метка scrubber ведёт к концу буквы
- [ ] На букве с малым числом статей scrubber скрыт или компактный (не ломает UI)
- [ ] Открытие статьи из списка → карточка; закрытие X / свайп вниз → снова указатель
- [ ] **Нет** полоски «Пометы» на указателе (только после KRL-поиска)

## 2. Направление поиска

- [ ] `kissa` / латиница → KRL-режим (выдача по словам)
- [ ] `кошка` / кириллица → RU-режим
- [ ] Пустой запрос + «Найти» / submit → возврат к указателю (без вечного спиннера)

## 3. Карельский поиск

- [ ] Точное слово из словаря находится (напр. полная лемма без опечатки)
- [ ] Часть слова **без** `?` / `.` **не** даёт префиксный «хвост» (нет авто-`%`)
- [ ] `boi?` (или аналог) → префикс через шаблон; есть хиты
- [ ] `.` = одна буква (напр. шаблон с точкой на известном слове)
- [ ] š/č/ž без птичек; `ü`/`y` взаимозаменяемы в запросе
- [ ] Апострофы в запросе не мешают (hilla ≈ hil’l’a)
- [ ] Пустая выдача: «Ничего не найдено.»; при опечатке — блок «Возможно вы искали:» с чипами
- [ ] Тап по suggestion подставляет слово и находит статью
- [ ] Большая KRL-выдача: scrubber / окна страниц работают как у указателя

## 4. Пометы (только KRL)

- [ ] После KRL с **разнородными** пометами видна полоска «Пометы»
- [ ] `kazi` (или другая выдача с одной общей пометой) — полоски **нет**
- [ ] Sheet: группы (грамматика / стиль / говор / НП), radio в группе, AND между группами
- [ ] Неприменимые чипы disabled (серые), активный можно снять
- [ ] Фразеологизмы — чекбокс; появляется только при контрасте в выдаче
- [ ] Сброс в sheet очищает фильтры; выдача возвращается к primary
- [ ] Чипы на полоске удаляют фильтр; список обновляется
- [ ] После смены буквы / выхода из поиска фильтры сбрасываются

## 5. Русский поиск

- [ ] Префикс: `кош` → кошка, кошелёк… (или актуальные хиты)
- [ ] `ё` ≈ `е`
- [ ] Пустая выдача — сообщение без KRL-suggestions
- [ ] **Нет** кнопок «точный смысл» / лемм / `?f=`

## 6. Карточка статьи

- [ ] HTML читаем: переводы, пометы, примеры; дополнения если есть
- [ ] Заголовок: нормализованная / clear-орфография, не сырой мусор с `||`
- [ ] Ссылка «см.» → push в стек; system back → предыдущая карточка
- [ ] Цепочка из 2–3 «см.» / «от»; back по шагам; X закрывает весь лист
- [ ] Открытие закладки из drawer не уводит фокус в поиск и не сбрасывает карточку

## 7. Закладки

- [ ] Звезда на карточке: добавить → SnackBar «Добавлено в закладки»
- [ ] Повтор → убрать → SnackBar «Убрано из закладок»
- [ ] При полном лимите (100) ★ на новой статье → SnackBar про лимит, список не растёт
- [ ] Список в drawer: порядок (новые сверху), тап открывает статью
- [ ] Свайп удаляет + SnackBar; пункт пропадает
- [ ] Перезапуск приложения — закладки на месте (вне пакета БД)

## 8. Меню / справка

- [ ] «Как искать» — текст про exact KRL, `.`/`?`, RU-префикс, fuzzy
- [ ] «О словаре» — кратко + ссылка на сайт (откроется в браузере)
- [ ] «О приложении» — версия совпадает с `pubspec` versionName
- [ ] Sideload / USB: в «О приложении» есть «Проверить обновление»
- [ ] После проверки: при большем `version_code` на сервере — «Скачать» → `/app/apk/`
- [ ] (Если доступна установка «как из стора») кнопка проверки приложения скрыта
- [ ] Back из вложенной pane drawer → список пунктов меню

## 9. Обновление БД

- [ ] Offline: «Проверить обновление» → понятная ошибка сети / нет краша; seed/runtime остаётся
- [ ] Online (prod `/mobile-pack/` или LAN mock): проверка манифеста, показ версии/размера
- [ ] Загрузка + установка: прогресс, после — новая `data_version` в UI; словарь открывается
- [ ] Закладки после update БД **сохраняются**
- [ ] Повторная проверка: «уже актуально» (если пакет тот же)

## 10. Краевые / стабильность

- [ ] Быстрые повторные поиски не зависают на спиннере
- [ ] Поворот / смена focus не ломает выдачу (по возможности)
- [ ] System back на главном экране без карточки — ожидаемое поведение ОС (не краш)
