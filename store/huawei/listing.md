## Название в магазине

**Словарь тверского карельского языка**

Альтернатива ближе к изданию: «Словарь карельского языка (тверские говоры)».

## Краткое описание

Офлайн-словарь тверского карельского языка Пунжиной: указатель, поиск KRL/RU, карточки статей без интернета.

## Полное описание

Электронная версия «Словаря карельского языка (тверские говоры)» А. В. Пунжиной (1994) для Android.

В приложении:

- алфавитный указатель по карельским буквам;
- поиск по карельскому (с шаблонами `.` / `?`) и по русским переводам;
- карточки статей со ссылками «см.» / «от»;
- закладки и пометы;
- работа полностью офлайн; при желании — обновление базы с сайта.

Расширенный поиск и материалы сайта сюда не входят — полная версия: https://punzhina.krc.karelia.ru  
Правообладатель: КарНЦ РАН.
